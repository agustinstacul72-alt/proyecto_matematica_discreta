## Ejecutar

En Windows, desde la raíz del proyecto:

```powershell
.\mvnw.cmd javafx:run
```

En macOS o Linux:

```bash
bash ./mvnw javafx:run
```

Desde IntelIJ Idea:
  Ejecutar el proyecto desde el archivo Launcher.java
